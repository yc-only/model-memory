# 模块索引规范

索引是 `ModelMemorys/model-link.json`。只通过 `upsert_module.py` 修改。文件不存在时，首次创建模块会在仓库根自动生成空索引；查询和校验不创建它，缺少索引时返回 `{"ok": false}`。

## 字段

| 字段 | 规则 |
|---|---|
| `name` | 小写字母、数字、连字符；等于记忆目录名 |
| `desc` | 一句话，只用于快速判断。权威描述在 `memory.md` |
| `source_roots` | 一条或多条源码根目录，相对仓库根，用 `/` |
| `memory_path` | 相对 `ModelMemorys/`，形如 `./<name>` |

定位不靠关键词。查询路径等于某个 `source_root`，或位于其下，才算命中。多个模块同时命中时，脚本只返回路径更深的模块；深度相同则全部返回，按 `desc` 和改动范围选择，不合并记忆。未命中时结果为空，不靠目录名相似度猜测。

`source_root` 必须是仓库内已经存在的目录。指向不存在的路径或单个文件时，创建和更新都会失败。

已知模块名时用 `--name` 查询，不用源码路径猜测：

```powershell
python .agents/skills/model-memory/scripts/search_modules.py --name billing
```

## 命令

创建：

```powershell
python .agents/skills/model-memory/scripts/upsert_module.py --name billing --desc "订单创建与支付结果确认" --source-root src/billing
```

更新给出的字段。`--source-root` 可重复，给出即整体替换旧列表：

```powershell
python .agents/skills/model-memory/scripts/upsert_module.py --name billing --desc "新的一句话"
```

只从索引移除，不删除记忆目录：

```powershell
python .agents/skills/model-memory/scripts/upsert_module.py --name billing --remove
```

脚本只生成 `memory.md` 和空的 `content/`。需要展开时再新建对应碎片，正文按 [记忆编写原则](./记忆编写原则.md) 填写。
